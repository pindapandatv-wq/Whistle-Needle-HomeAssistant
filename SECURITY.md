# Security policy

Whistle Assist can trigger Home Assistant device actions. Treat reports about incorrect actuation, entity exposure bypass, confirmation bypass, arbitrary service execution, or unintended outbound data as security-sensitive.

Please do not publish a working exploit or sensitive household information in a public issue. Use GitHub's private vulnerability reporting feature for this repository when it is enabled. If private reporting is not enabled, contact the repository owner through a private GitHub channel and request a secure disclosure route.

There is no guaranteed response time for this experimental project. Until a fix is released, disable the integration or remove it from voice-assistant pipelines if you suspect a security issue.
